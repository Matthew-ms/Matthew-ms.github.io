Privacy Policy

Last updated: October 19, 2026

Personal Assistant is a private bot used only by its owner. This policy describes how it handles Google user data.

What it accesses

With the owner's permission, the bot reads and creates events on the owner's own Google Calendar. It does not access any other Google data or any other person's account.

How the data is used

Calendar access is used only to create the events the owner asks for and confirms, and to answer the owner's questions about their own schedule.

To understand a request, the text of the owner's chat message is sent to Anthropic's Claude API. Google Calendar data is not used to train any AI model.

Storage and sharing

The access token Google issues is stored only on the owner's own server. Google user data is not sold, and is not shared with anyone except as needed to process the owner's own requests as described above.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions.
